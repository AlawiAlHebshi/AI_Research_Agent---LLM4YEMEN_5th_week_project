# Streamlit المتصل — التشغيل المحلي والاختبار

الواجهة تستعمل `run_research` الموجود، وليس وكيلاً ثانيًا. يتولى
`streamlit_backend.BackendGateway` إنشاء جلسة الميزانية والسياق المناسب، ثم
يحوّل النتيجة المتحققة إلى `BackendResult`. لا تغييرات على `main.py` أو
`memory.py` أو إعدادات أدوات MCP لهذه المهمة.

## التشغيل

من جذر المشروع، باستعمال الحزم الموجودة:

```powershell
.\.venv\Scripts\python.exe -B -m streamlit run streamlit_app.py --server.address 127.0.0.1 --server.port 8502
```

افتح `http://127.0.0.1:8502/`. لا تستعمل `python streamlit_app.py` مباشرة.
النشر غير منفذ. لا تغيّر العنوان إلى `0.0.0.0` ولا تعرض الخدمة للعامة؛ هذه
واجهة محلية لمشغل واحد بلا مصادقة. المظهر وRTL/LTR وCSS من الواجهة السابقة.
مراقبة الملفات معطّلة؛ أعد تشغيل الخادم بعد تعديل Python باستخدام `Ctrl+C`
في طرفيته ثم الأمر أعلاه. مراقبة الملفات وإحصاءات الاستخدام معطلتان في إعداد المشروع.

**الواجهة لا تقرأ `.env`.** إذا كان المفتاح متاحًا للـCLI عن طريق `.env` فقط،
فلن يصل تلقائيًا إلى Streamlit. يبقى زر البحث معطلًا مع رسالة واضحة حتى
تجهز `OPENAI_API_KEY` في بيئة العملية ثم تعيد تشغيل الخادم منها.
إذا لم يكن المتغير مهيأً، يمكنك بنفسك إدخاله إدخالًا مخفيًا في PowerShell:

```powershell
$researchKey = Read-Host "OpenAI API key" -AsSecureString
$env:OPENAI_API_KEY = [System.Net.NetworkCredential]::new("", $researchKey).Password
.\.venv\Scripts\python.exe -B -m streamlit run streamlit_app.py --server.address 127.0.0.1 --server.port 8502
```

لا تطبع المتغير أو تضع المفتاح في السؤال أو تشاركه في المحادثة. هذه أوامر إعداد
يدوية للمستخدم، ولم يشغّلها Codex ولم يقرأ قيمة المفتاح. Asta اختياري عند تهيئة
`ASTA_TOOL_KEY` في بيئة الخادم، ومفاتيح المصادر العلمية الاختيارية تبقى كما هي.
إعداد SQLite عبر `RESEARCH_MEMORY_DB` في بيئة العملية يخضع لقيود `memory.py` الحالية.

## تجربة الواجهة بعد مراجعة التنفيذ

1. اترك «وضع العرض التجريبي» معطّلًا للوضع المتصل. اختيار المثال يعبئ السؤال فقط.
2. اختر البحث في الويب أو العلمي واكتب سؤالًا، ثم اضغط «ابدأ البحث». هذه الخطوة
   وحدها قد تنفق رصيد API. تبقى الميزانية $0.03 للمهمة، $0.30 لليوم، $5 للمشروع،
   وحد الاستدعاءات 10، وحدود السياق والإخراج والتحقق كما هي.
3. أثناء البحث تظهر حالة وتقدم مبنيان على أحداث المحرك. المؤشر تقريبي للمراحل،
   وليس تقديرًا دقيقًا للوقت. لا تعرض الأدوات الخام أو التعليمات أو ترويسات الاتصال.
4. تُعرض النتيجة فقط بعد التحقق: الملخص، وروابط الاستشهادات والمصادر، والأدوات،
   والتوكنات والتكلفة المحسوبة. حالة `degraded` ظاهرة بوضوح، وليست نجاحًا دون قيود.
5. افتح «الأبحاث السابقة» وابحث بجزء من السؤال أو العنوان، ثم افتح سجلًا.
   البيانات من SQLite دون نموذج؛ تظهر علامة «بحث سابق» والتاريخ والنمط والحالة.
   لا يعاد التحقق من المراجع التاريخية ولا تضاف إلى أدلة أي بحث جديد.
6. افتح تبويب التقرير. التنزيل يُجهّز النص في الذاكرة؛ لا يكتب ملفًا على الخادم
   ولا يستدعي النموذج. حفظ الخادم يبقى معطلًا حتى توافق صراحةً، ثم يعاد استخدام
   `save_report_to_disk` بحماية المسار واسم فريد وفتح الملف دون استبدال.
7. جرّب تبديل اللغة والتبويبات وفتح التاريخ والحفظ والتنزيل؛ لا تعيد هذه الخطوات
   البحث. ملخص البحث ونص السؤال الأصلي لا يُترجمان إلى بيانات جديدة عند تبديل اللغة.

استعراض التاريخ محدود بخمسة سجلات مطابقة في العرض الحالي. قسم التقارير يعرض
أسماء الملفات المحفوظة في جلسة الواجهة والتقرير النشط؛ ليس مستعرضًا عامًا لكل
ملفات مجلد `reports/`. الملفات المحفوظة نفسها تبقى على القرص بعد انتهاء الجلسة.

## منع التكرار وإدارة الجلسة

- ينشأ المحوّل مرة لكل جلسة، ولا يستعمل كائن نموذج أو بيانات جلسة مشتركة عالميًا.
- لا يُستدعى البحث إلا داخل فرع إرسال المستخدم. تتغير هوية الطلب فقط عند إرسال
  جديد، وتُحفظ نتيجته أو فشله؛ إعادة الطلب بالهوية نفسها لا تستدعي النموذج مجددًا.
- تكرار السؤال نفسه يحتاج موافقة منفصلة على تكلفة جديدة. تُستهلك الموافقة مرة
  واحدة، وتُعرض خانة غير محددة للمحاولة التالية حتى لا تسبب نقرتان بحثين إضافيين.
- لا توجد إعادة محاولة مدفوعة تلقائية بعد الخطأ أو انقطاع الاتصال. تبقى الحجوزات
  غير المسوّاة في سجل الميزانية. لا تُصفّر عدادات أو يُرحّل التتبع المالي إلى SQLite.
- النتيجة الحالية تبقى في الجلسة، والنتائج المتحققة تُسجل في SQLite بالطريقة الحالية.
  لا يُعرض بحث قديم بوصفه جوابًا عن محاولة جديدة فاشلة.
- إعادة تحميل المتصفح أو فقدان الجلسة قد يفقد الحالة المؤقتة؛ افتح البحث من SQLite
  بدل تشغيله مجددًا. منع تكرار الطلبات هنا ضمن الجلسة وليس ضمانًا موزعًا عبر الأجهزة.

## الذاكرة والخصوصية

المالك الحالي هو نطاق `local` الذي يستعمله CLI. استعلامات SQLite تظل مقيدة
بذلك النطاق؛ لا يوجد حقل يسمح بتبديل مالك من المتصفح. هذا ليس تسجيل دخول أو
عزلًا آمنًا متعدد المستخدمين. مستخدمو المتصفح على الجهاز نفسه ممن يملكون الوصول
للخدمة المحلية يرون مساحة المشغل المحلية نفسها؛ لا تعرض الخدمة على جهاز مشترك
غير موثوق أو على الشبكة قبل مرحلة المصادقة والأمان المعتمدة.

يبقى اختيار المرحلة السابقة قائمًا: لا تُرسل مقتطفات الذاكرة السابقة للنموذج.
استعراض سجل لا ينشئ أثر تنفيذ بحث جديد. للبحث الحقيقي آثار خاصة بنوع
`streamlit` داخل `.runtime/traces/`، ولحفظ التقرير أثر إجراء منفصل بلا استدعاء
نموذج. لا يعرض المتصفح محتويات الآثار. تصدير أدلة CLI السابق لم يتغير ولا يحول
سجلات الاختبار أو Streamlit إلى سجلات CLI.

## العرض التجريبي المتبقي

خيار صريح في الشريط الجانبي يعيد العرض السابق بعينات ثابتة وعلامة DEMO.
حالاته والحفظ في ذاكرة العرض محلية فقط، دون OpenAI أو MCP أو SQLite أو ملفات
تقارير. بياناته مستقلة عن حالة الوضع المتصل، ولا يُستبدل بها بحث حي فاشل.

## الاختبارات المنفذة دون إنفاق API

```powershell
.\.venv\Scripts\python.exe -B -m unittest discover -s tests -p test_streamlit_backend.py -v
.\.venv\Scripts\python.exe -B -m unittest discover -s tests -p test_ui_connected.py -v
.\.venv\Scripts\python.exe -B -m unittest discover -s tests -q
```

نجحت المجموعة الكاملة: **187 اختبارًا**، منها 11 للمحوّل و10 للواجهة المتصلة.
بعد التحصين الأخير لموافقة التكرار أعيدت اختبارات الواجهة العشرة ونجحت كلها.
يعمل المحرك وLangChain وSDK وحجز الميزانية فعليًا في الاختبارات، لكن HTTP
والخدمات تُحاكى محليًا، والاتصال الخارجي محظور. قواعد الاختبار وآثارها داخل
`.runtime/tests/`، والتقارير الاصطناعية داخل `reports/.tests/`، ولا تدخل تاريخ المستخدم.

شملت الاختبارات النمطين، وروابط الاستشهاد، ورفض الناتج غير المتحقق، وفشل
المزود، وحظر الميزانية قبل النقل، والاتصال الفاشل وحفظ حجزه، والتاريخ بعد
جلسة واجهة جديدة، والموافقة على الحفظ وعدم استبدال الملف، والتنزيل، وإعادة
العرض وتبديل اللغة، ومنع التكرار، وغياب إعداد المفتاح، واستقلال DEMO.

ظهر خلل تنسيق خيارات القوائم بعد تبديل اللغة أثناء AppTest؛ صُحح بتثبيت لغة
تنسيق كل عرض وإعادة إرسال القيم نفسها. ظهرت تحذيرات AppTest المعتادة عن
`ScriptRunContext`؛ لم تكن إخفاقات بحث أو اتصالات مدفوعة.

أُطلق الخادم محليًا على 8502 وفُتحت صفحة البداية الفعلية في المتصفح. كان زر
البحث معطلًا لغياب مفتاح العملية؛ لم يُضغط ولم يُجر بحث OpenAI مدفوع. لا حزم
مثبتة أو منزّلة في هذه المهمة، ولا تغيير في `cost_analysis.md` أو عدادات الاستخدام.

## الحدود الباقية

لم تُجر اختبارات بحث مدفوعة أو اختبارات توافق حي جديدة لمزودي MCP؛ يجريها
المستخدم بعد المراجعة. تبقى قيود المزودين وأخطاء 429 وغياب مفتاح Asta مؤثرة.
لم يُنفذ نشر أو مصادقة أو مرحلة اختبار الأمان النهائية، ولم يتغير المحرك أو
تعليماته أو قواعد التحقق من المصادر. بعض رسائل المحرك تبقى بلغتها الأصلية
عند تبديل لغة الواجهة؛ لا يُستخدم نموذج لترجمة الأخطاء أو الأبحاث.
